# Nexo Digital

Nexo Digital es un sitio web educativo de ejemplo que presenta rutas introductorias de programación, desarrollo web y ciberseguridad. El proyecto utiliza HTML5 y CSS3, sin procesos de compilación ni dependencias adicionales.

## Tecnologías
- HTML5
- CSS3
- Diseño adaptable a pantallas pequeñas

## Cómo clonar y ejecutar el proyecto

1. Copia la URL HTTPS del repositorio desde GitHub.
2. Abre una terminal y ejecuta:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

3. Entra a la carpeta:

   ```bash
   cd Proyecto-Web-Ejemplo
   ```

4. Abre `index.html` en un navegador. También puedes abrir la carpeta en Visual Studio Code y utilizar la extensión Live Server si la tienes instalada.

## Archivos principales
- `index.html`: estructura y contenido de la página.
- `styles.css`: colores, distribución, tipografía y diseño adaptable.
- `README.md`: documentación del proyecto.

## Ramas del proyecto
- `main`: versión principal y estable del sitio web.
- `feature-mejora-estilo`: rama de trabajo para implementar mejoras visuales y de presentación antes de integrarlas en `main`.

## Funcionalidad implementada
- Navegación interna entre secciones.
- Presentación de tres rutas de aprendizaje.
- Diseño adaptable para escritorio y móvil.
- Enlaces de navegación a las secciones de cursos, información y contacto.

## Autoría
Proyecto educativo realizado como práctica del curso de Git y GitHub.
